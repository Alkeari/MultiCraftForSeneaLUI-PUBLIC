## v1.0.3 - 2026-10-19

- Changed: The Thunderstore page now states only the SeneaL UI versions this mod was verified on; the mod itself is unchanged from 1.0.2.

## v1.0.2 - 2026-10-12

- Fixed: With SeneaL UI 1.1.8 or later, this mod no longer logs an error every frame.
- Fixed: With SeneaL UI 1.1.8 or later and MultiCraft installed, a batch from SeneaL UI's own amount stepper crafts the whole amount instead of one item.
- Changed: On SeneaL UI 1.1.8 and later this mod's amount control stays off and SeneaL UI's own stepper is used, which D-Pad Left and Right now change.

## v1.0.1 - 2026-10-01

- Changed: The mod itself is unchanged from 1.0.0.

## v1.0.0 - 2026-10-01

- Added: A "- N +" amount control next to SeneaL UI's craft button that sets MultiCraft's craft amount.
- Added: Shift+click steps the amount by MultiCraft's bulk step, Ctrl+click on + jumps to the maximum and Ctrl+click on - returns to 1.
- Added: Controller D-Pad Left and Right change the amount in SeneaL UI's crafting window.
- Added: A plain click on SeneaL UI's craft button crafts the chosen amount as one craft with one timer.
- Removed: SeneaL UI's Shift craft hint from the crafting window's controls banner, since Shift now crafts the same amount as a plain click.
- Fixed: Crafting more than one item from SeneaL UI's crafting window while MultiCraft is installed.
